# Supply Chain Mastery Project

## Overview

This project is an Excel-based supply chain analytics and planning model designed to evaluate operational performance, inventory health, and replenishment requirements.

The workbook combines order, shipment, inventory, and supplier data to generate practical supply chain KPIs and support inventory planning decisions.

## Objectives

- Measure order fulfillment performance
- Analyze inventory health
- Identify high-value products
- Support replenishment planning
- Calculate optimal order quantities
- Forecast future demand
- Evaluate supplier and operational performance

## Key Analysis

### Order Fulfillment

The project evaluates order execution using important fulfillment indicators such as:

- OTIF
- On-Time Delivery
- In-Full Delivery
- Perfect Order Performance
- Fulfillment Lead Time

These metrics help identify gaps in delivery and order fulfillment performance.

### Inventory Analysis

Inventory performance is evaluated using metrics including:

- Inventory Value
- Inventory Turnover
- Days of Inventory
- Annual Demand
- Product-Level Inventory Position

These indicators provide an overview of inventory efficiency and stock availability.

### ABC Analysis

Products are classified using ABC/Pareto analysis based on their contribution to overall inventory or sales value.

This helps prioritize inventory management by identifying products that require closer monitoring.

### Reorder and EOQ Planning

The project includes inventory planning calculations for:

- Safety Stock
- Reorder Point
- Economic Order Quantity (EOQ)
- Current Stock Position

These calculations help determine when inventory should be replenished and the approximate quantity to order.

### Demand Forecasting

Historical demand is analyzed using a moving-average forecasting approach.

Forecast accuracy is evaluated using MAPE to compare predicted demand with actual demand.
